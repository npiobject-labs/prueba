Arranque de un proyecto

Crear · desde el móvil

  1. 1 · Crear el repo desde la plantilla

    github.com/new?template_name=DesdeMovil&template_owner=npiobject-labs → Owner npiobject-labs, nombre MiProyecto, Public (si no, no hereda FLY_API_TOKEN), Create.

    El workflow Inicializar plantilla renombra todo solo. El primer run de Pages sale en rojo: es normal.

  2. 2 · Pages → origen "GitHub Actions"

    github.com/npiobject-labs/MiProyecto/settings/pages → Source: cambia Deploy from a branch por GitHub Actions.

    Si lo dejas como viene, verás el README en vez del mock.

  3. 3 · Primera sesión de Code

    App de Claude → Code → repo npiobject-labs/MiProyecto → pega:

    Verifica que el proyecto quedó inicializado y que Pages responde. Si sigue existiendo .plantilla-pendiente, lanza el workflow "Inicializar plantilla" y espera. Dime SHA, URL de Pages y build.

    Listo cuando npiobject-labs.github.io/MiProyecto/ muestra "MiProyecto · mock 0".

Después · solo si hace falta

  • Fly (backend): nada que activar. FLY_API_TOKEN es secreto de la organización npiobject-labs y lo heredan sus repos públicos: el siguiente push que toque app/** despliega (o Actions → Desplegar backend en Fly.io → Run workflow). URL: https://miproyecto-npiobject-labs.fly.dev/salud.
  • Drive (copias): carpeta normal en Mi unidad → id de la URL → pedir a la sesión: "pon este id en Parámetros de CLAUDE.md".
  • Aterrizar en el PC: PowerShell → & ([scriptblock]::Create((irm https://raw.githubusercontent.com/npiobject-labs/DesdeMovil/main/tools/aterrizar.ps1))) -Proyecto MiProyecto. Deja C - Desarrollo\MiProyecto\repo. No editar ahí.
  • Borrar el proyecto: Fly (solo la app; el token es de la organización y no se revoca) → GitHub (Settings → Danger Zone) → carpeta de Drive → sesiones de Code y carpeta del PC.
Guía completa con explicaciones: docs/guiaNew.html en npiobject-labs/DesdeMovil. Las casillas se guardan en este navegador.
